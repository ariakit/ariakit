## Overview

These samples build navigation with the Ariakit UI `Nav` components. Most samples show only the navigation, with placeholders where the rest of the page would be. The Sidebar Sections and Top Bar samples use the `Shell` components to show full pages. Open them in a new tab and resize the window to see how they adapt.

The gallery includes a list of links, a list with a brand selection, a top bar, course lessons, a workspace sidebar, a sidebar with collapsible sections and thumbnails, an API reference, a music library, and repository tabs.

## Components

`Nav` renders a navigation landmark with a list of `NavLink` rows. Set `$layout="horizontal"` for a row that scrolls when the links need more room. Pass `glider` to mark the current link with a cover that moves between links. Pass `{ $kind: "bar" }` for a thin bar instead, or an array to show a cover and a bar together.

Set `aria-current="page"` on the current `NavLink`, or pass `currentUrl` to compare it with the `href`. Put an icon, badge, avatar, shortcut, or thumbnail in a `NavSlot`, and the text in a `NavLinkLabel`. Wrap a label and a `NavLinkDescription` in `NavLinkContent` to show secondary text below or beside the label.

`NavGroup` and `NavGroupLabel` put rows under a small heading. Set `$divider` on a group to draw a line before it, or `$uppercase` on a label to show it in small uppercase letters. `NavDisclosure` shows nested rows in a collapsible section. `NavDisclosureGroup` puts sections in a shared frame with dividers. Set `$fill` on the group and on the `Nav` in a sidebar, and the open section takes the height that the closed sections leave and scrolls its own rows.

## Accessibility

Give each `Nav` a name with `aria-label` or `aria-labelledby`, because a page can have more than one navigation landmark. When the element around the navigation is already the landmark, such as a sidebar rendered as `nav`, render the `Nav` as a `div`.

A `NavLinkDescription` becomes the accessible description of its link, so the label and the slots name the link and the description adds detail. A link that shows only an icon still needs a name.

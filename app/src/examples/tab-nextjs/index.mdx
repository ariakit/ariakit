## Overview

This sample keeps the selected tab in the URL with the Next.js App Router. Each tab is a link to its own route, so the Back and Forward buttons, reloads, and shared links all keep the same tab selected. Use the address bar above the preview to see the route change when you select a tab.

The posts for each route render in a parallel `@tabs` route on the server. The layout around them stays mounted, so only the panel content changes when you switch tabs.

## Components

The sample uses the workspace's `@ariakit/ui` Tab components. `TabProvider` reads the selected tab from `usePathname` and calls `router.push` when the selected tab changes. It also takes a stable `id`, because the tab store would otherwise generate a random one, which Cache Components rejects while it prerenders the route. A `div` with the `tabs` style frames the tab list and the panels. `Tab` renders a Next.js `Link` through the `render` prop. `TabPanel` with the `single` prop shows the content of the selected route in one panel inside `TabPanels`.

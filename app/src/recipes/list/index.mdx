## Overview

These examples build lists with the Ariakit UI `List` components. A list groups related items in rows. Each row has a marker, such as a dash, a bullet, a number, an icon, or a check, and a guide can join the markers.

The gallery starts with a plain list. Then it shows bullets joined by a guide, ordered steps, a list of icons, lists in an article, a task list that reports live progress, an onboarding checklist, an activity timeline with icons, and the stages of an order in a row. The last examples show rows that open: steps with details, and a checklist that opens one step at a time.

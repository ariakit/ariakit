## Overview

These examples build complete page layouts with the Ariakit UI `Shell` components. Each example is a full page, so headers stick and sidebars scroll with the page. Open a preview in a new tab and resize the window to see how the sidebars fold at narrow widths.

## Components

`Shell` places a header, up to two sidebars per side, a main area, and a footer in one CSS grid. Put a `Shell` inside another `Shell` to give a sidebar the full page height beside the header. `ShellMain` holds an optional sticky `ShellMainHeader`, a `ShellMainIntro`, and a `ShellMainBody`. Use `ShellMainPopout`, `ShellMainFeature`, and `ShellMainFull` to make content wider than the centered column.

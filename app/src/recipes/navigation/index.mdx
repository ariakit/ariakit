## Overview

These examples build navigation with the Ariakit UI `Nav` components. Most examples show only the navigation, with placeholders where the rest of the page would be. The Accordion Sections and Top Bar examples use the `Shell` components to show full pages. Open them in a new tab and resize the window to see how they adapt.

The gallery includes a list of links, a list with a brand selection, a top bar, course lessons, a workspace sidebar, a sidebar with collapsible sections and thumbnails, an API reference, a music library, repository tabs, and a feed with links in a segmented control.

## Components

`Nav` renders a navigation landmark with a list of `NavLink` rows. Set `$layout="horizontal"` for a row that scrolls when the links need more room. The current link keeps its own surface. Pass `bar` to also mark it with a thin bar, or `bar={{ $offset: "halfway" }}` to center it between the link and the navigation edge. Set `bar` on a `NavLink` to override the default for that link.

When the current link changes in a view transition, the bar moves from the old link to the new one. When the old bar is outside a horizontal `Nav` that scrolls, it stays out of the transition, so the bar does not fly in from outside the row. The new bar then fades in. Give the transition the `bar` type, as with React's `addTransitionType("bar")`, so the page stays out of the transition and keeps taking clicks. `Nav` names its bar with a unique id, so a bar that moves across page loads needs `$barTransitionName` with the same name on both pages. Set `$barTransitionName="none"` to keep the bar out of view transitions.

Set `aria-current="page"` on the current `NavLink`, or pass `currentUrl` to compare it with the `href`. Put an icon, badge, avatar, shortcut, or thumbnail in a `NavSlot`, and the text in a `NavLinkLabel`. In a horizontal row, the current link uses the normal weight unless it gets its plain text through `text`, as in `<NavLink text="Overview" />`, or through `<NavLinkLabel text="Issues" />` beside slots. The label then reserves the width of the heavier text, so the current link turns heavier without moving the links after it. Wrap a label and a `NavLinkDescription` in `NavLinkContent` to show secondary text below or beside the label.

Set `$kind="segmented"` on a horizontal `Nav` and on its `NavLink` elements to show the links as a segmented control, as in the Segmented Links with an Inverted Thumb example. The current link is the selected segment, and the links stay in a navigation landmark. Set `$invert` on the links to invert only the current one.

`NavGroup` and `NavGroupLabel` put rows under a small heading. Set `$divider` on a group to draw a line before it, or `$uppercase` on a label to show it in small uppercase letters. `NavDisclosure` shows nested rows in a collapsible section. `NavDisclosureGroup` puts sections in a shared frame with dividers. Set `$fill` on the group and on the `Nav` in a sidebar, and the open section takes the height that the closed sections leave and scrolls its own rows.

## Accessibility

Give each `Nav` a name with `aria-label` or `aria-labelledby`, because a page can have more than one navigation landmark. A `Nav` inside a `Nav` landmark or a `ShellSidebar` with `landmark="nav"` renders a `div`, so the rows don't repeat the landmark around them. Leave that `Nav` without a name, because a name keeps its own landmark. When the landmark around it renders outside the React tree, such as an Astro sidebar around an island, set `landmark={false}` on the `Nav`.

A `NavLinkDescription` becomes the accessible description of its link, so the label and the slots name the link and the description adds detail. A link that shows only an icon still needs a name.
